Welcome to your expense tracker!

This is a simple tool to track your daily spending habits. Simply input an item alongside a cost, and the program will automatically add up your spending throughout the day!

When you want to see where your spending is at, use 'list' for a list of your purchases so far, as well as a running total.
When you're finished spending for the day, use 'end' for a finalised total.

Happy spending! :)
